Sobre o LASI

O Laboratório de Sistemas Inteligentes (LASI) é um grupo de pesquisa dedicado ao estudo e desenvolvimento de sistemas inteligentes, incluindo inteligência artificial, aprendizado de máquina e robótica. Nosso objetivo é criar soluções inovadoras para desafios complexos em diversas áreas, como saúde, educação e indústria.

Projetos Recentes

  • Projeto A: Desenvolvimento de um sistema de reconhecimento de voz para assistentes virtuais.
  • Projeto B: Implementação de um algoritmo de aprendizado de máquina para análise de dados médicos.
  • Projeto C: Criação de um robô autônomo para tarefas domésticas.
